# 数学赛车 3D · Math Racer 3D

一个把**小学数学练习**融入**3D 赛车**的网页小游戏。孩子开着小车在公路上飞驰，
穿过写着正确答案的「闸门」赚取金币，再用金币在车库里**购买新车并改装**。

> 目前主打**两位数加减法**，难度可手动选择，也可随表现**自动升降**。

![预览](https://img.shields.io/badge/Three.js-r160-blue) ![无需联网](https://img.shields.io/badge/离线可玩-yes-green)

## 玩法

1. 在主菜单选择**难度**（或勾选「自动调整难度」），点击 **开始游戏**。
2. 车头前方会不断出现题目，例如 `47 + 28 = ?`，三条车道上各有一个候选答案。
3. **把车开进正确答案的车道**即可：
   - ✅ 答对：获得分数和金币，连对还有额外奖励（连对越多奖励越高）。
   - ❌ 答错或错过：扣 1 颗 ❤️，扣光 3 颗心本局结束。
4. 局末把赚到的金币带回**车库**，购买新车型并改装。

### 操作
- **键盘**：`←/→` 或 `A/D` 切换车道，`Esc/P` 暂停。
- **触屏 / 鼠标**：点击屏幕左右半区，或使用屏幕下方的 ◀ ▶ 按钮。

## 难度系统

| 等级 | 名称 | 内容 |
|----|------|------|
| LV1 | 新手上路 | 两位数加减·**不进退位**，两个选项 |
| LV2 | 稳步前进 | 两位数加减·**含进退位**，两个选项 |
| LV3 | 渐入佳境 | 两位数混合·**三个选项** |
| LV4 | 高手挑战 | 更大的数·车速更快 |
| LV5 | 闪电飞驰 | **连加连减**（三个数）·三选项 |
| LV6 | 数学车神 | 极限速度·全随机 |

- **手动**：在主菜单直接选等级。
- **自动**（默认开启）：连对 4 题自动升一级，连错 2 题自动降一级，难度随能力动态匹配。
- 车速随难度递增，留给孩子读题和反应的时间相应缩短，形成自然的挑战梯度。

## 车库与改装

- **12 款车型**：入门两厢车、城市轿车、敞篷跑车、GT 跑车、肌肉车、都市 SUV、皮卡、
  欢乐巴士、怪兽越野、复古甲壳、超级跑车、幻影银箭——价格从免费到 3500 金币不等。
- **改装项**（已拥有的车可改装）：
  - 车身颜色（12 色）
  - 车漆质感（亮面 / 哑光 / 金属）
  - 轮毂样式（标准 / 运动 / 越野）
  - 轮毂颜色（6 色）
  - 尾翼（有 / 无）
- 所有车型与改装都是用 Three.js **程序化几何体**实时生成，**不依赖任何外部模型素材**，
  后续想加新车只需在 `js/carFactory.js` 的 `MODELS` 里加一条配置。
- 金币、已购车辆、改装方案、最好成绩都保存在浏览器 **localStorage**，下次打开仍在。

## 运行方式

**直接双击 `index.html` 即可离线游玩**，无需联网、无需服务器。

全部代码（含 Three.js）已打包进 `dist/game.bundle.js` 这一个普通脚本，浏览器以
`file://` 方式打开也不会被模块跨域策略拦住。只要保证 `index.html`、`css/`、
`dist/` 三者在一起即可。

> 小提示：个别浏览器在 `file://` 下会限制 `localStorage`，导致进度不被保存（游戏照常能玩）。
> 若希望存档可靠，用下面任意一种方式起个本地服务器再打开即可：
>
> ```bash
> npm run serve          # = python3 -m http.server 8080，访问 http://localhost:8080
> # 或 npx serve .
> # 或 VS Code 的 “Live Server” 插件，右键 index.html → Open with Live Server
> ```

## 修改源码后重新打包

源码在 `js/*.js`（ES Modules）。改完后需重新构建出 `dist/game.bundle.js`：

```bash
npm install      # 首次：安装 esbuild 与 three（仅构建时需要）
npm run build    # 打包；或 npm run watch 监听改动自动重打包
```

## 目录结构

```
.
├── index.html              # 入口与界面骨架（加载打包脚本）
├── css/style.css           # 全部样式（菜单 / 车库 / HUD / 结算）
├── dist/
│   └── game.bundle.js      # 打包产物：含 Three.js 的单文件，离线直开
├── package.json            # 构建脚本（esbuild）
└── js/                     # 源码（ES Modules）
    ├── main.js             # 主控制器：渲染循环、界面切换、输入
    ├── game.js             # 玩法场景：道路、车辆、答案闸门、判定与计分
    ├── carFactory.js       # 程序化生成 12 款车型 + 改装
    ├── garage.js           # 车库 3D 转台预览 + 购买/改装 UI
    ├── math.js             # 出题与难度系统（两位数加减、自动调难）
    ├── storage.js          # localStorage 存档
    └── audio.js            # WebAudio 合成音效（无音频素材）
```

> 改完 `js/` 下的源码后记得 `npm run build` 重新生成 `dist/game.bundle.js`。

## 二次开发提示
- **加新车**：编辑 `js/carFactory.js` 的 `MODELS` 数组，并在 `BODY_PRESETS` 里增/改车身预设。
- **改难度或题型**：编辑 `js/math.js` 的 `DIFFICULTY_LEVELS` 和 `generateExpression`
  （例如未来加入乘除法或三位数）。
- **调平衡**：金币奖励在 `js/game.js` 的 `_evaluateRound`，车速在 `js/math.js` 的 `speedForLevel`。
